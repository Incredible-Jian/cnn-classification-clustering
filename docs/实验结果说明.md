# 实验结果说明

## 分类结果

| 指标 | CIFAR-10 | CIFAR-100 |
|---|---|---|
| 测试 Accuracy | 87.54% | 60.08% |
| Top-3 Accuracy | 98.0% | 81.4% |
| Top-5 Accuracy | 99.6% | 88.5% |
| Macro F1 | 0.8742 | 0.5949 |
| 随机水平 | 10.0% | 1.0% |

## 聚类结果（冻结 ImageNet 特征）

| 指标 | CIFAR-10 (K=10) | CIFAR-100 (K=100) |
|---|---|---|
| ARI | 0.3382 | 0.1616 |
| NMI | 0.4796 | 0.4874 |
| Purity | 0.5527 | 0.3074 |
| Silhouette | 0.0379 | 0.0291 |
| 耗时(s) | 5.3 | 55.0 |

## 聚类结果（微调 Backbone 特征，补充）

| 指标 | CIFAR-10 (K=10) | CIFAR-100 (K=100) |
|---|---|---|
| ARI | 0.7498 | 0.3316 |
| NMI | 0.7588 | 0.6251 |
| Purity | 0.8755 | 0.4791 |

## 主要结论

1. 同一 ResNet18 Backbone 可同时服务 CIFAR-10 和 CIFAR-100。
2. 在相同训练样本量下，类别数从 10 增加到 100，分类和聚类指标均下降。
3. K-Means 对细粒度类别的聚类能力有限（ARI 明显低于 Accuracy）。
4. Hugging Face Trainer + sklearn MiniBatchKMeans 满足课程全部要求。

> 所有数值来自由 main.ipynb 真实运行的结果。
